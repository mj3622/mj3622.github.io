# 🌟 关于我 | About Me

你好，我是 Minjer，一名后端开发工程师，也喜欢参与和维护开源项目

平时主要使用 Java，也会用 Python 和 TypeScript 做一些自己用得上的工具。这里的不少项目都来自很具体的需求：下载和整理轻小说、处理 EPUB、追踪更新，或者给日麻练习做一个趁手的网页

这个博客主要记录 Java 后端、框架源码和工程实践，偶尔也会写自动化工具、日语学习和自己的项目。很多文章最初只是给自己留一份能回看的笔记，如果也能帮到刚好遇见同一个问题的人，就更好了

## 💼 开源项目 | Open Source Projects

> 轻小说文库下载器：基于 TypeScript + Electron 的桌面应用，可以检索作品、下载插图并按整本或分卷导出 EPUB，支持 macOS 和 Windows，项目主页：[wenku8.minjer.top](https://wenku8.minjer.top/)

::github{repo="mj3622/Wenku8Downloader"}

> 轻小说更新提醒：定时检查收藏作品是否更新，新章节发布后通过邮件或飞书机器人发送通知

::github{repo="mj3622/NoveliaReminder"}

> EPUB 合并工具：文件全程在浏览器本地处理，可以拖拽排序、编辑元数据，并生成兼容 EPUB 2/3 目录的合并电子书，在线：[epub-merger.minjer.top](https://epub-merger.minjer.top/)

::github{repo="mj3622/epub-merger"}

> 简繁转换助手：批量将 TXT 和 EPUB 文件从繁体中文转换为简体中文，保留原有资源和文件结构

::github{repo="mj3622/simplified-traditional-converter"}

> 日麻何切る在线练习：提供分类题库、逐题解析与牌效信息，帮助练习中盘切牌判断，在线：[nani-kiru.minjer.top](https://nani-kiru.minjer.top/)

::github{repo="mj3622/nani-kiru"}

> 日语新闻学习工具：定时抓取日文新闻，借助 AI 清理正文、生成翻译与语法点解析，再通过邮件发送

::github{repo="mj3622/SakuraDigest"}
